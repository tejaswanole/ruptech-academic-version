# ruptech-website

Next.js source for the Ruptech Engineers website. See the [repository README](../README.md) for setup, configuration and environment variables.

```bash
npm install
npm run dev
```

Main folders:

- `src/app/` pages, API routes (`api/contact`, `api/rfq`), sitemap, robots and icons
- `src/components/` shared UI components
- `src/lib/constants.js` business details (address, email, phone, WhatsApp, GSTIN)
- `src/lib/productData.js` product specifications from the printed catalogue
- `public/` logo, product images and the catalogue PDF
